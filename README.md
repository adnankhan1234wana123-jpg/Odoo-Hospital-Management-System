# Odoo-Hospital-Management-System
## Features
- Patient registration and record management
- Appointment booking and scheduling for doctors
- Doctor management with specialization details
- Prescription creation and tracking
- Role-based access (Admin, Doctor, Receptionist)

## Installation
1. Copy this module into your Odoo `addons` folder
2. Restart the Odoo server
3. Go to Apps → Update Apps List
4. Search for "Hospital Management" and click Install

## Tech Stack
- Python
- Odoo Framework
- XML (Views)
